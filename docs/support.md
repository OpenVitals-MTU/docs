# Support OpenVitals

OpenVitals is an independent open-source project focused on local-first health data tools for Android.

If you need help using the app, start with the user docs below. If OpenVitals is useful to you, financial support helps fund development, testing, documentation, and maintenance without adding accounts, ads, analytics, or cloud sync to the local app.

## Translate The App

You can support OpenVitals by translating the Android app into your language on Codeberg Translate:

[Translate OpenVitals](https://translate.codeberg.org/projects/openvitals/android-app/){ .md-button .md-button--primary }

Translations help make the local-first health dashboard usable for more people without changing the app's privacy model.

## Fund Development

OpenVitals is free and open source. Contributions through Liberapay fund the ongoing development, testing, documentation, releases, and maintenance needed to keep the project moving. Funding does not change the app's local-first model: the Android app remains free of accounts, ads, analytics, and OpenVitals cloud sync.

## What Support Helps With

- Keeping up with Health Connect and Android platform changes.
- Testing real-world health metric flows across devices and providers.
- Improving translations, documentation, screenshots, and release notes.
- Maintaining a privacy-first app without in-app tracking or ads.

Thank you for helping keep OpenVitals sustainable.
