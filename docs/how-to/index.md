# How-to Guides

These guides explain concrete user workflows that need more detail than a short feature page.

- [Add offline maps](/how-to/offline-maps): download PMTiles or Mapsforge map packs, import them into OpenVitals, choose the active render format, and troubleshoot common issues.
- [Add elevation tiles](/how-to/elevation-tiles): obtain SRTM `.hgt` tiles for your area, import them, and correct the altitude of imported routes.
- [Install the Wear OS app](/how-to/wear-os-sideload): pair a computer with the watch over Wi-Fi adb, skip the vendor onboarding on a new watch where possible, install the OpenVitals watch app, grant its permissions, and pair the phone.
